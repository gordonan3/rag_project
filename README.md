# RAG для корпоративной базы знаний

## Описание проекта

В данном проекте проводится исследование эффективности подхода Retrieval-Augmented Generation (RAG) для работы с закрытой корпоративной базой знаний.

Датасет содержит:

* 10 статей корпоративной базы знаний;
* 50 вопросов;
* эталонные ответы (ground truth).

Цель эксперимента — сравнить качество ответов моделей в двух режимах:

1. Zero-Shot (без доступа к базе знаний);
2. RAG (с использованием поиска по базе знаний).

# Архитектура RAG

## Индексация документов

Каждая статья формируется следующим образом:

```text
Заголовок статьи
+
Текст статьи
```

Для получения эмбеддингов используется модель:

```text
sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
```

Размерность эмбеддингов:

```text
384
```

---

## Поиск релевантного контекста

Для каждого вопроса:

```text
Вопрос
    ↓
Эмбеддинг вопроса
    ↓
Косинусное сходство
    ↓
Поиск наиболее релевантной статьи
```

---

## Генерация ответа

Полученный контекст передаётся в LLM:

```text
Контекст
+
Вопрос
    ↓
LLM
    ↓
Ответ
```

# Метрики оценки

Для оценки качества использовались:

## Автоматические метрики

* BLEU
* ROUGE-1
* ROUGE-2
* ROUGE-L

## LLM-as-a-Judge

Оценивались следующие критерии:

* factual_correctness — фактическая корректность;
* completeness — полнота ответа;
* relevance — релевантность ответа вопросу;
* hallucination — отсутствие галлюцинаций;
* score — итоговая оценка.

Шкала:

```text
0 — очень плохо
5 — отлично
```

## RAG

# Основные выводы

## Использование RAG значительно улучшает качество ответов

### Qwen 0.5B

```text
Score:
1.04 → 2.80

Рост: +169%
```

### Ministral 3B

```text
Score:
1.46 → 3.56

Рост: +144%
```

---

## Существенно выросла фактическая корректность ответов

### Qwen

```text
0.62 → 2.76
```

Рост более чем в 4 раза.

### Ministral

```text
1.28 → 3.56
```

Рост почти в 3 раза.

Это показывает, что механизм retrieval успешно доставляет модели релевантные факты из базы знаний.

---

## Значительно снизилось количество галлюцинаций

Наилучший результат показала связка:

```text
RAG + Ministral-3B
```

Полученное значение:

```text
Hallucination = 4.94 / 5
```

что свидетельствует о практически полном отсутствии выдуманных фактов в ответах модели.

# Итог

Проведённый эксперимент подтверждает эффективность подхода RAG для работы с корпоративными базами знаний.

Наилучшие результаты показала архитектура:

```text
Retriever
+
Ministral-3B-Instruct
```

По сравнению с режимом Zero-Shot использование RAG позволило:

* значительно увеличить ROUGE и BLEU;
* повысить фактическую корректность ответов;
* уменьшить количество галлюцинаций;
* повысить релевантность и полноту ответов.

Полученные результаты демонстрируют, что даже простой RAG-пайплайн способен существенно улучшить качество ответов.
